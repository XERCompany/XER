# Демо: VST3 + CEF (`XER_VST3_CEF.exe`)

[English](README_en.md) | [Русский](README_ru.md)

Десктопное демо, встраивающее нативный редактор VST3-плагина и вид
браузера CEF (Chromium Embedded Framework) внутри UI-фреймворка XER,
с загрузкой аудиофайлов, выводом через WASAPI и цепочкой обработки VST3.

## Возможности

- **VST3-вид** — выбор пути плагина, встраивание нативного HWND
  редактора, байпас по правому клику на каждый плагин
- **CEF-вид** — встроенный браузер Chromium с элементами навигации
- **Аудио-цепочка** — загрузка аудиофайла → `AudioEngine` → стадии
  VST3 → вывод WASAPI; плагины активируются (`setActive`) и обрабатывают
  стерео
- **Сканирование плагинов** — через `EngineScanVST3.exe`: по дочернему
  процессу `--probe` на каждый `.vst3`-модуль, `std::async` с
  ограничением по числу ядер CPU

## Файлы

| Файл | Назначение |
|---|---|
| `vst3_cef.h/.cc` | Окно демо: VST3-хост + CEF-браузер |
| `xbrowser.cc` | Интеграция браузера CEF |
| `CMakeLists.txt` | Цель `XER_VST3_CEF` |

## Примечания

- Некоторые VST3-плагины — интерактивные генераторы (например,
  capture/riser-типы) и намеренно выдают тишину без собственного
  сценария — используйте байпас по правому клику, чтобы услышать
  сухой сигнал.
- Бандлы `.vst3` резолвятся через `Contents\x86_64-win\*.vst3`;
  метаданные `Contents\Resources\moduleinfo.json` выбирают
  аудио-классы.
