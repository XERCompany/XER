# xbuild Scaffold Implementation Plan

**Goal:** Add the user-selected scaffold for a separate `xbuild` utility inside XER.

**Architecture:** A C++23 executable reads `project.json` through libuv and JsonCpp. Configuration loading and validation live separately from LLVM-based CLI parsing. CMake supports both inclusion in XER and standalone configuration.

**Tech Stack:** C++23, CMake 3.21+, Clang/LLVM, Abseil, libuv, JsonCpp, RE2, range-v3 from vcpkg, CTest.

**Spec:** The supplied project.json example, the user's choice of a scaffold with CLI and configuration validation, and the subsequent instruction to use the seven vcpkg libraries above. Build execution is deferred.

## Constraints

- Preserve the supplied `terimal_*` field spelling.
- Accept JSON comments, but reject duplicate keys, trailing data and malformed JSON.
- Validate field types and required target/source structure; expressions remain opaque strings.
- Do not execute hooks, evaluate expressions, compile sources or fetch dependencies.
- Discover the requested dependencies through vcpkg CMake packages; use their APIs where applicable to the scaffold.

## Review Focus

- Invalid nested values must report their JSON path.
- Duplicate target names and keys must fail rather than silently overwrite data.
- A configuration with enabled integrations must still only be validated.
- Paths containing spaces and a missing configuration must produce predictable CLI results.
- Standalone configuration must not require XER's media or V8 dependencies.

## Execution Record

The selected scope authorizes creating the scaffold directly. Work stays in the shared workspace for review; no commits or external operations are required.

- The initial CLI test failed against the empty executable, then passed after implementation.
- A deeply nested JSON input exposed an uncaught JsonCpp exception. The reader now limits depth and catches parser exceptions.
- Both standalone and integrated builds pass the CLI test; the integrated configuration also passes dependency and V8-preparation smoke tests.
- MSVC reports C4702 warnings in the installed Abseil template headers.
- `XER_BUILD_XBUILD` defaults to OFF; its dedicated preset enables it. This keeps the compiler dependencies opt-in for other XER configurations.
