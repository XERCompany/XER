# SQL

[English](README_en.md) | [Русский](README_ru.md)

`Engine::SQL` — слой персистентности на SQLite.

- `content/` определяет привязываемые SQL-значения.
- `modern/` содержит типы параметризованных запросов.
- `storage/` владеет соединениями SQLite и исполняет запросы.
- `plus/` предоставляет хелперы транзакций.
- `orm/` описывает таблицы и создаёт безопасный schema SQL.

Реализация собирается как `XERSQL`, когда доступен SQLite3. Значения
привязываются через prepared statements; значения запросов никогда не
интерполируются в текст SQL.
