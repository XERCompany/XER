# Аудио-подсистема

[English](README_en.md) | [Русский](README_ru.md)

Каталог `src/audio` содержит аудио-конвейер проекта и DSP-ориентированный
функционал. Он рассчитан на обработку сигналов, работу с медиафайлами,
логику эффектов и интеграцию с остальным рантаймом.

## Область

- аудио-движок и основной путь обработки
- DSP-алгоритмы и спектральная обработка
- встроенные эффекты и обработка через плагины
- анализ и извлечение метаданных
- файловый I/O для распространённых медиаформатов
- опциональные медиа-интеграции и пути ускорения

## Основные области

- `audio_core/` — ядро аудио-движка, загрузка источников,
  virtual audio cable (именованные межпроцессные PCM-каналы,
  мосты WASAPI, цепочка FX/VST3 на каждый канал)
- `dsp_algorithms/` — FFT, фильтры, преобразования и блоки обработки
- `effects_rack/` — цепочка эффектов и утилиты конвейера обработки
- `analysis_ai/` — анализ и извлечение признаков
- `file_io_codecs/` — работа с медиаформатами
- `plugin_wrappers/` — точки интеграции хостов плагинов (сканирование
  VST3 через изолированные процессы `EngineScanVST3.exe --probe`,
  `std::async` с ограничением по числу ядер CPU)

## Цели дизайна

- модульный конвейер обработки аудио
- аппаратно-ориентированные и SIMD-дружественные пути реализации
- поддержка асинхронной и пакетной обработки
- интеграция с рантаймом и I/O-инфраструктурой

## Пример

```cpp
Engine::Audio::Core::AudioSourceLoadOptions opts;
opts.input_path = "audio.mp3";
opts.target_sample_rate = 48000;
opts.target_channels = 2;

Engine::Audio::Core::AudioSourceBuffer buffer;
std::string error;
if (!Engine::Audio::Core::AudioSourceLoader::Load(opts, &buffer, &error)) {
    // обработка ошибки
}
```

## Примечания

Подсистема намеренно расширяема и обслуживает как лёгкие задачи аудио
рантайма, так и тяжёлые медиа-конвейеры. Точный набор функций зависит от
активной конфигурации сборки и доступных платформенных библиотек.
