# Интеграция OpenAI

[English](README_en.md) | [Русский](README_ru.md)

Каталог `src/content/openai` предоставляет компактный слой интеграции для
OpenAI-подобных API и связанных LLM-процессов.

## Область

- доступ к OpenAI-клиенту
- чат и prompt-ориентированные взаимодействия
- абстракции агентов и скиллов
- хелперы обработки текста, изображений и аудио
- концепции серверной маршрутизации запросов
- интеграция с другими подсистемами XER: сеть, async I/O, аудио

## Типичная архитектура

- `client/` — транспорт API и создание запросов
- `agent/` — абстракции агентов и логика оркестрации
- `skills/` — переиспользуемые возможности или tool-подобные функции
- `sandbox/` — изолированное окружение исполнения кода или процессов
- `image/` — генерация или обработка изображений
- `text/` — анализ, саммаризация и генерация текста
- `server/` — серверная маршрутизация запросов

## Связь с остальным проектом

Подсистема спроектирована для встраивания в больший рантайм XER, а не как
самостоятельный продукт. Она может использовать сетевые и асинхронные
примитивы проекта и должна сосуществовать с другими контентными и
медиа-подсистемами.

## Пример

```cpp
#include "content/openai/openai.h"

using namespace Content::OpenAI;

auto client = Client::ClientFactory::CreateFromEnv();
auto response = client->CreateChatCompletion(messages).get();
```

## Примечания

Точные доступные функции модуля зависят от выбранной конфигурации сборки и
набора зависимостей. Этот README — высокоуровневый обзор точек интеграции
и обязанностей, а не строгая спецификация всех рантайм-возможностей.
