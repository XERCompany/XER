# Сетевая подсистема

[English](README_en.md) | [Русский](README_ru.md)

Каталог `src/content/network` содержит сетевой стек проекта. Он задуман
как переиспользуемый, слоистый сетевой фундамент для компонентов рантайма
и приложения.

## Область

- логика HTTP и HTTPS
- работа с URL и жизненный цикл запросов/ответов
- сокеты и транспортные абстракции
- поддержка DNS, прокси и сертификатов
- событийные и асинхронные паттерны исполнения сети
- интеграция с I/O и инфраструктурой рантайма

## Слоистая структура

- `core/` — сетевой контекст и рантайм сервиса
- `url/` — обработка запросов/ответов и разбор URL
- `http/` — поведение протокола HTTP
- `socket/` — низкоуровневые абстракции сокетов
- `dns/` — резолюция DNS, поиски и кэширование
- `proxy/` — конфигурация прокси и туннелирование
- `cert/` — управление и верификация сертификатов

## Цели дизайна

- чистое разделение между слоями протокола, транспорта и политики
- совместимость с асинхронными паттернами исполнения
- безопасная интеграция с остальным рантаймом
- поддержка слоистых сетевых сценариев без навязывания единого стиля API

## Пример

```cpp
#include "content/network/url/url_request_util.h"

std::string response = network::url::SyncGet("https://example.com");
```

## Примечания

Модуль — часть общей архитектуры рантайма и рассматривается как
переиспользуемый сетевой фундамент, а не самостоятельная реализация
веб-сервера. Конкретная поддержка протоколов и глубина функций зависят от
текущей конфигурации сборки и зависимостей проекта.
